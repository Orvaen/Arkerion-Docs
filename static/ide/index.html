Arkerion Mono (v5, proportions recalées sur une police de code éprouvée) est une esquisse à chasse fixe (600/1000) dérivée de la proposition Code. Elle est dessinée pour une lecture plus fluide : épaules qui naissent du fût en douceur, rondes plus souples, léger contraste, terminaisons qui suivent le trait, queues courbes sur i, l et y. Le zéro est pointé, la ponctuation agrandie, et les ligatures de code (-> <- => == === != !== <= >= <=>) occupent exactement leurs cellules pour préserver l'alignement. Elle sert à la zone de code ; Arkerion Sans reste la police de l'interface.

  
Les trois propositions comptent maintenant l'alphabet complet, les chiffres (tabulaires), la ponctuation, les symboles de code et les accents français courants. Seules les lettres de « Arkerion » sont dessinées au niveau final de l'étude ; les autres sont des esquisses construites sur les mêmes paramètres. Un caractère absent du jeu s'affiche dans la police de secours du système.
