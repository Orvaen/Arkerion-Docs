01 / Logo

Le symbole Structure

Le symbole associe une équerre et un bloc emboîté dans son angle. L'équerre évoque la construction et la rigueur ; le bloc, le module de code qui vient s'y loger. Les angles sont arrondis pour garder une forme sobre et accessible.

03 / Couleurs

Noir, blanc et un seul accent

L'identité repose sur le noir et le blanc. Les gris servent à la hiérarchie de l'interface ; le bleu est réservé aux liens, aux états actifs et au focus. Il ne sert jamais de fond de grande surface.

Proportions indicatives : blanc 46 %, noir 34 %, gris 16 %, bleu 4 %.

05 / Code

Le code dans les supports Arkerion

Les extraits de code sont toujours composés en Arkerion Mono, sur fond très clair, avec une coloration discrète. Le texte autour reste en Arkerion Sans.

nebula.config.tsTypeScript
import { defineConfig } from "@arkerion/sdk";

// Configuration du projet Nebula
export default defineConfig({
  name: "nebula",
  region: "eu-west-3",
  build: { command: "npm run build", output: "dist" },
  healthCheck: (res) => res.status >= 200 && res.status !== 503,
});

Dans le texte, le code s'écrit en ligne : npm run build, defineConfig(), process.env.PORT.

07 / Statut et suite

Ce qui reste à faire

Les polices de ce document sont des versions d'étude. Elles couvrent l'alphabet latin de base, les chiffres, la ponctuation de code et les accents français courants.

  1. Valider le logo définitif et produire les fichiers (SVG, PNG, PDF) dans toutes les versions.
  2. Reprendre Arkerion Sans et Arkerion Mono dans un éditeur de polices : fusion des contours, hinting, guillemets français, tiret long et ligature des lettres o et e.
  3. Dessiner les graisses Medium, Semibold et Bold.
  4. Exporter les polices en TTF, OTF et WOFF2.
