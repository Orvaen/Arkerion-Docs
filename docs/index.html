Prise en main / Démarrage rapide

Démarrage rapide

Installez la CLI Arkerion, connectez votre compte et déployez votre premier projet en moins de cinq minutes.

i

Prérequis. Node.js 20 ou plus récent, et un compte Arkerion. La CLI fonctionne sous macOS, Linux et Windows.

Installation

La CLI est distribuée sous forme de paquet npm. Choisissez votre gestionnaire de paquets :

npm install -g @arkerion/cli
pnpm add -g @arkerion/cli
yarn global add @arkerion/cli

Vérifiez ensuite l'installation avec arkerion --version. La commande doit afficher 2.4.0 ou une version plus récente.

Authentification

Ouvrir une session

La commande ouvre votre navigateur et associe la CLI à votre compte.

Terminal
arkerion login

Créer une clé d'API

Pour l'intégration continue, utilisez plutôt une clé d'API et exposez-la dans la variable ARKERION_API_KEY.

Terminal
arkerion keys create --name "ci-production" --scope deploy
export ARKERION_API_KEY=ark_live_7f3a9c21e4b8
!

Attention. Une clé d'API donne un accès complet à vos projets. Ne la publiez jamais dans un dépôt Git ; stockez-la dans les secrets de votre plateforme.

Configuration

Chaque projet est décrit par un fichier arkerion.config.ts à la racine du dépôt. Le typage est fourni par le SDK.

arkerion.config.ts
import { defineConfig } from "@arkerion/sdk";

export default defineConfig({
  name: "arkerion-core",
  region: "eu-west-3",
  runtime: "node20",
  build: {
    command: "npm run build",
    output: "dist",
  },
  // Les routes sont évaluées dans l'ordre
  routes: [
    { path: "/api/*", target: "server" },
    { path: "/*", target: "static", cache: 3600 },
  ],
  healthCheck: (res) => res.status >= 200 && res.status !== 503,
});

Appeler l'API

Le SDK TypeScript gère l'authentification, les nouvelles tentatives et la pagination. Voici comment lister vos projets et ajouter une étoile au premier :

projects.ts
import { Arkerion } from "@arkerion/sdk";

const client = new Arkerion({ apiKey: process.env.ARKERION_API_KEY });

async function main(): Promise<void> {
  const { data: projects } = await client.projects.list({ limit: 20 });
  if (projects.length === 0) return;

  const first = projects[0];
  await client.projects.star(first.id);
  console.log(`Projet ${first.name} : ${first.stars + 1} étoiles`);
}

main().catch((err) => process.exit(1));

Commandes utiles

  • arkerion deploy déploie la branche courante sur un environnement de prévisualisation.
  • arkerion deploy --prod promeut la dernière version en production.
  • arkerion logs -f affiche les journaux en continu.
  • arkerion env pull récupère les variables d'environnement dans .env.local.

Limites et quotas

Les requêtes à l'API sont limitées à 600 par minute et par clé. Au-delà, l'API répond 429 Too Many Requests avec un en-tête Retry-After en secondes.
