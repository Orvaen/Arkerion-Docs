# Polices

Les fichiers des polices se trouvent dans [`static/fonts`](https://github.com/Orvaen/Arkerion-Docs/tree/main/static/fonts), aux formats TTF et OTF.

| Fichier | Police |
|---|---|
| `ArkerionSans-Regular.ttf` / `.otf` | Arkerion Sans Regular |
| `ArkerionMono-Regular.ttf` / `.otf` | Arkerion Mono Regular |
| `v2/ArkerionSans-Regular-v2.otf` / `.ttf` | Arkerion Sans v2 : lettres du nom Arkerion redessinées ([détails](./arkerion-sans-v2)) |
| `etudes/ArkerionSans-Clarte.ttf` | Variante d'étude Clarté |
| `etudes/ArkerionSans-Nuance.ttf` | Variante d'étude Nuance |

## Sur un site web

Copiez les fichiers TTF dans votre projet, puis déclarez les polices en CSS :

```css title="fonts.css"
@font-face {
  font-family: "Arkerion Sans";
  src: url("./fonts/ArkerionSans-Regular.ttf") format("truetype");
  font-display: swap;
}

@font-face {
  font-family: "Arkerion Mono";
  src: url("./fonts/ArkerionMono-Regular.ttf") format("truetype");
  font-display: swap;
}

body {
  font-family: "Arkerion Sans", system-ui, sans-serif;
}

code, pre {
  font-family: "Arkerion Mono", ui-monospace, monospace;
  font-feature-settings: "calt" 1; /* ligatures de code */
}
```

## Dans un éditeur de code

<Tabs groupId="editeur">
  <TabItem value="vscode" label="VS Code" default>

Installez `ArkerionMono-Regular.ttf` sur votre système, puis ajoutez dans `settings.json` :

```json title="settings.json"
{
  "editor.fontFamily": "'Arkerion Mono', monospace",
  "editor.fontLigatures": true,
  "editor.fontSize": 14,
  "editor.lineHeight": 1.6
}
```

  </TabItem>
  <TabItem value="jetbrains" label="IDE JetBrains">

Installez `ArkerionMono-Regular.ttf`, puis ouvrez **Settings**, **Editor**, **Font** : choisissez *Arkerion Mono* et cochez **Enable ligatures**.

  </TabItem>
  <TabItem value="terminal" label="Terminal">

Dans la plupart des terminaux, choisissez *Arkerion Mono* dans les préférences de police. Les ligatures dépendent du terminal : elles fonctionnent par exemple dans Kitty, WezTerm et iTerm2.

  </TabItem>

## Statut

:::caution Versions d'étude : Arkerion Sans 0.9, Arkerion Mono 0.1
En 0.2, le p, le q, le b, le d et le r d'Arkerion Sans sont reconstruits à partir de l'arche du n : panses plus droites, jonctions plus fines, et un r au bras plus long coupé à plat (script `sources/retouches_v0_2.py`).

En 0.3, le o et le O sont élargis (+45 et +61 unités) en gardant leur ovale, leurs épaisseurs et leur espacement ; ô et Q suivent (script `sources/retouches_v0_3.py`).

En 0.4, le A devient le seul glyphe à empattements de la police : sommet en pointe, jambe gauche fine, jambe droite appuyée, barre basse légèrement montante, pieds à empattements raccordés en courbe. Dessin original inspiré du A de Lora ; À suit (script `sources/retouches_v0_4.py`).

En 0.5, le c et le ç sont élargis de 55 unités : la moitié droite s'écarte, les terminaisons et les épaisseurs restent les mêmes (script `sources/retouches_v0_5.py`).

En 0.6, le f est redessiné en f géométrique (fût presque centré, quart de cercle vers un bras horizontal plat, barre aussi large que le bras), et le a et le e prennent 55 unités de large ; leurs accents suivent (script `sources/retouches_v0_6.py`).

En 0.7, le e et ses accents prennent 25 unités de plus, ce qui les rend légèrement plus larges que le o (591 contre 581 unités de chasse) (script `sources/retouches_v0_7.py`).

En 0.8, le p, le q, le b et le d prennent 60 unités de large, et le g est refait dans la même famille : panse du q, queue en quart de cercle vers un bras plat, comme le f retourné (script `sources/retouches_v0_8.py`).

En 0.9, le a est redessiné : grande panse au dessus plat, crochet rond coupé à l'horizontale, raccord en biseau entre la panse et le fût, 572 unités de chasse comme le p et le g ; à et â suivent (script `sources/retouches_v0_9.py`).

Les polices sont générées par paramètres à partir des sources du dossier `sources/`. Avant un usage en production :

1. reprendre les dessins dans un éditeur de polices (FontLab, Glyphs) et fusionner les contours qui se chevauchent ;
2. ajouter le hinting pour la netteté à petite taille sous Windows ;
3. compléter le jeu de caractères : guillemets français, tiret long, points de suspension, ligatures des lettres o et e ;
4. dessiner les graisses Medium, Semibold et Bold, puis exporter en WOFF2.
:::
