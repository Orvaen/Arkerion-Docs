# Couleurs

L'identité repose sur le noir et le blanc. Les gris servent à la hiérarchie de l'interface. Une seule couleur vient les ponctuer : le <mark>Jaune Arkerion</mark>, la couleur signature de la marque.

## Proportions

Sur un support type, le blanc domine, le noir porte le texte et le logo, les gris structurent, et le jaune reste ponctuel.

| Couleur | Part indicative |
|---|---|
| Papier | 46 % |
| Encre | 34 % |
| Gris | 16 % |
| Jaune Arkerion | 4 % |

## Le Jaune Arkerion

Le jaune agit comme un surligneur posé sur une page noir et blanc. Sélectionnez une phrase de cette page : c'est la couleur de sélection de tout le site.

| Usage | Règle |
|---|---|
| Sélection de texte | fond jaune, texte en encre |
| Liens | texte en encre, soulignement jaune de 2 px |
| Élément actif (menu, sommaire, navigation) | barre ou soulignement jaune |
| Focus clavier | contour jaune de 2 px |
| Lignes de code mises en avant | fond jaune très léger et liseré jaune |

:::tip
Le jaune ne s'écrit jamais en texte sur fond blanc : son contraste est trop faible. Pour un texte jaune sur blanc, utilisez le Jaune texte `#8A6100`. Sur fond noir, le Jaune Arkerion s'utilise tel quel.
:::

:::warning
Le jaune ne sert jamais de grand aplat de fond, et il ne colore jamais le logo, qui reste noir ou blanc.
:::
