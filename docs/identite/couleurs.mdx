# Couleurs

L'identité repose sur un charbon posé sur un fond clair et neutre, doux pour les yeux. Les gris brume et pierre servent à la hiérarchie de l'interface. Une seule couleur vient les ponctuer : l'<mark>Améthyste Arkerion</mark>, la couleur signature de la marque.

La base est une gamme de gris neutres, à peine teintés d'améthyste pour s'accorder à la couleur signature, sans tirer vers le jaune ni vers le bleu (`#FAFAFB` `#F0EFF3` `#D5D3DB` `#8D8A94` `#26252B`). Deux teintes intermédiaires, *Texte courant* et *Légendes*, servent au texte : l'ardoise `#8D8A94` n'atteint que 3,3:1 sur le fond, elle ne porte donc pas de texte.

## Proportions

Sur un support type, le fond neige domine, le charbon porte le texte et le logo, les gris brume et pierre structurent, et l'améthyste reste ponctuelle.

| Couleur | Part indicative |
|---|---|
| Neige | 46 % |
| Charbon | 34 % |
| Brume, pierre, ardoise | 16 % |
| Améthyste Arkerion | 4 % |

## L'Améthyste Arkerion

L'améthyste ponctue une page claire et charbon. Sélectionnez une phrase de cette page : c'est la couleur de sélection de tout le site.

| Usage | Règle |
|---|---|
| Sélection de texte | voile améthyste translucide, le texte garde sa couleur |
| Liens | texte améthyste, souligné au survol |
| Élément actif (menu, sommaire, navigation) | barre ou soulignement améthyste |
| Focus clavier | contour améthyste de 2 px |
| Lignes de code mises en avant | fond améthyste très léger et liseré |

:::tip
L'Améthyste `#6E569F` s'utilise en texte sur le fond clair (contraste de 5,8:1). Sur fond sombre, utilisez sa version claire `#B4A4D6`.
:::

:::warning
L'améthyste ne sert jamais de grand aplat de fond, et elle ne colore jamais le logo, qui reste charbon ou blanc.
:::

## Variables CSS

```css title="couleurs.css"
:root {
  --ark-paper: #fafafb;       /* neige */
  --ark-wash: #f0eff3;        /* brume */
  --ark-stone: #d5d3db;       /* pierre */
  --ark-taupe: #8d8a94;       /* ardoise */
  --ark-ink: #26252b;         /* charbon */
  --ark-soft: #47454e;        /* texte courant */
  --ark-mute: #68656f;        /* légendes */
  --ark-signal: #6e569f;      /* Améthyste Arkerion */
  --ark-signal-soft: rgba(110, 86, 159, 0.12);
  --ark-signal-dark: #b4a4d6; /* sur fond sombre */
}

::selection {
  background: color-mix(in lch, #7a62b8, transparent 64%);
  color: currentColor;
}
```
