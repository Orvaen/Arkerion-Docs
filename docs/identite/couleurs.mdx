# Couleurs

L'identité repose sur le noir et le blanc. Les gris servent à la hiérarchie de l'interface. Une seule couleur vient les ponctuer : l'<mark>Améthyste Arkerion</mark>, la couleur signature de la marque.

## Proportions

Sur un support type, le blanc domine, le noir porte le texte et le logo, les gris structurent, et l'améthyste reste ponctuelle.

| Couleur | Part indicative |
|---|---|
| Papier | 46 % |
| Encre | 34 % |
| Gris | 16 % |
| Améthyste Arkerion | 4 % |

## L'Améthyste Arkerion

L'améthyste ponctue une page noir et blanc. Sélectionnez une phrase de cette page : c'est la couleur de sélection de tout le site.

| Usage | Règle |
|---|---|
| Sélection de texte | aplat améthyste, texte blanc |
| Liens | texte améthyste, souligné au survol |
| Élément actif (menu, sommaire, navigation) | barre ou soulignement améthyste |
| Focus clavier | contour améthyste de 2 px |
| Lignes de code mises en avant | fond améthyste très léger et liseré |

:::tip
L'Améthyste `#7C4DDB` s'utilise en texte sur fond blanc (contraste de 5,3:1). Sur fond sombre, utilisez sa version claire `#A98BF0`.
:::

:::warning
L'améthyste ne sert jamais de grand aplat de fond, et elle ne colore jamais le logo, qui reste noir ou blanc.
:::
