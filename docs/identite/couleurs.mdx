# Couleurs

L'identité repose sur le noir et le blanc. Les gris servent à la hiérarchie de l'interface ; le bleu est réservé aux liens, aux états actifs et au focus.

## Proportions

Sur un support type, le blanc domine, le noir porte le texte et le logo, les gris structurent, et le bleu reste ponctuel.

| Couleur | Part indicative |
|---|---|
| Papier | 46 % |
| Encre | 34 % |
| Gris | 16 % |
| Bleu Arkerion | 4 % |

:::tip
Le bleu ne sert jamais de fond de grande surface. Pour mettre un élément en avant, préférez le contraste noir sur blanc.
:::
