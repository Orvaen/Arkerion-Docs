# Couleurs

L'identité repose sur un charbon posé sur un fond crème, comme un mur de galerie sous une lumière douce. Les gris perle et pierre servent à la hiérarchie de l'interface. Une seule couleur vient les ponctuer : l'<mark>Améthyste Arkerion</mark>, la couleur signature de la marque.

La base vient de la palette crème « Gris Perle Minimaliste » (`#FFF3DB` `#ECE7DD` `#CFC9BE` `#8E8A83` `#2A2A2A`). Deux teintes intermédiaires, *Texte courant* et *Légendes*, en sont dérivées pour que le texte reste lisible : le taupe `#8E8A83` n'atteint que 3,1:1 sur la crème, il ne porte donc pas de texte.

## Proportions

Sur un support type, la crème domine, le charbon porte le texte et le logo, les gris perle et pierre structurent, et l'améthyste reste ponctuelle.

| Couleur | Part indicative |
|---|---|
| Crème | 46 % |
| Charbon | 34 % |
| Perle, pierre, taupe | 16 % |
| Améthyste Arkerion | 4 % |

## L'Améthyste Arkerion

L'améthyste ponctue une page crème et charbon. Sélectionnez une phrase de cette page : c'est la couleur de sélection de tout le site.

| Usage | Règle |
|---|---|
| Sélection de texte | voile améthyste translucide, le texte garde sa couleur |
| Liens | texte améthyste, souligné au survol |
| Élément actif (menu, sommaire, navigation) | barre ou soulignement améthyste |
| Focus clavier | contour améthyste de 2 px |
| Lignes de code mises en avant | fond améthyste très léger et liseré |

:::tip
L'Améthyste `#6E569F` s'utilise en texte sur la crème (contraste de 5,5:1). Sur fond sombre, utilisez sa version claire `#B4A4D6`.
:::

:::warning
L'améthyste ne sert jamais de grand aplat de fond, et elle ne colore jamais le logo, qui reste charbon ou crème.
:::

## Variables CSS

```css title="couleurs.css"
:root {
  --ark-paper: #fff3db;       /* crème */
  --ark-wash: #ece7dd;        /* perle */
  --ark-stone: #cfc9be;       /* pierre */
  --ark-taupe: #8e8a83;       /* taupe */
  --ark-ink: #2a2a2a;         /* charbon */
  --ark-soft: #4d4a45;        /* texte courant */
  --ark-mute: #6f6b64;        /* légendes */
  --ark-signal: #6e569f;      /* Améthyste Arkerion */
  --ark-signal-soft: rgba(110, 86, 159, 0.12);
  --ark-signal-dark: #b4a4d6; /* sur fond sombre */
}

::selection {
  background: color-mix(in lch, #7a62b8, transparent 64%);
  color: currentColor;
}
```
