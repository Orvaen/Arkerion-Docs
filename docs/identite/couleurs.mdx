# Couleurs

L'identité repose sur un charbon posé sur un fond blanc. Des gris neutres, sans teinte, servent à la hiérarchie de l'interface. Une seule couleur vient les ponctuer : l'<mark>Améthyste Arkerion</mark>, la couleur signature de la marque.

La base est un fond blanc et une gamme de gris parfaitement neutres (`#FFFFFF` `#F6F6F7` `#DCDCE0` `#8E8E96` `#1F1F23`). Sans teinte, ils laissent l'améthyste seule couleur de la page. Deux teintes intermédiaires, *Texte courant* et *Légendes*, servent au texte : l'ardoise `#8E8E96` n'atteint que 3,3:1 sur le fond, elle ne porte donc pas de texte.

## Proportions

Sur un support type, le fond blanc domine, le charbon porte le texte et le logo, les gris brume et pierre structurent, et l'améthyste reste ponctuelle.

| Couleur | Part indicative |
|---|---|
| Blanc | 46 % |
| Charbon | 34 % |
| Brume, pierre, ardoise | 16 % |
| Améthyste Arkerion | 4 % |

## L'Améthyste Arkerion

L'améthyste ponctue une page claire et charbon. Sélectionnez une phrase de cette page : c'est la couleur de sélection de tout le site.

| Usage | Règle |
|---|---|
| Sélection de texte | voile améthyste translucide, le texte garde sa couleur |
| Liens | texte améthyste, souligné au survol |
| Élément actif (menu, sommaire, navigation) | barre ou soulignement améthyste |
| Focus clavier | contour améthyste de 2 px |
| Lignes de code mises en avant | fond améthyste très léger et liseré |

:::tip
L'Améthyste `#6E569F` s'utilise en texte sur le fond blanc (contraste de 6:1). Sur fond sombre, utilisez sa version claire `#B4A4D6`.
:::

:::warning
L'améthyste ne sert jamais de grand aplat de fond, et elle ne colore jamais le logo, qui reste charbon ou blanc.
:::

  --ark-wash: #f6f6f7;        /* brume */
  --ark-stone: #dcdce0;       /* pierre */
  --ark-taupe: #8e8e96;       /* ardoise */
  --ark-ink: #1f1f23;         /* charbon */
  --ark-soft: #4a4a52;        /* texte courant */
  --ark-mute: #6b6b73;        /* légendes */
  --ark-signal: #6e569f;      /* Améthyste Arkerion */
  --ark-signal-soft: rgba(110, 86, 159, 0.12);
  --ark-signal-dark: #b4a4d6; /* sur fond sombre */
}

::selection {
  background: color-mix(in lch, #7a62b8, transparent 64%);
  color: currentColor;
}
