# Typographie

Arkerion utilise deux polices maison : **Arkerion Sans** pour l'interface, la documentation et le logo, et **Arkerion Mono** pour le code.

Pour comparer, le sélecteur **Arkerion / Système** en haut à droite affiche toute la documentation dans la police sans de votre système. Le code reste en Arkerion Mono, et les spécimens de cette page restent en Arkerion Sans.

## Arkerion Sans

Une grotesque d'interface : grande hauteur d'x, rondes tendues, ouvertures franches, dessinée pour rester nette à l'écran.

Le nom Arkerion se compose avec un interlettrage resserré de -2,5 % ; le texte courant garde l'espacement par défaut de la police.

## Arkerion Mono

Police à chasse fixe pour le code, les terminaux et les données. Le zéro est pointé, les lettres i, l et le chiffre 1 sont bien distincts, et la ponctuation est renforcée.

### Ligatures de code

Les ligatures sont activées par défaut. Elles ne modifient que l'affichage : le fichier contient toujours les caractères tapés, et chaque ligature occupe exactement la largeur des signes qu'elle remplace.
