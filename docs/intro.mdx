## Un aperçu du code

Les blocs de code utilisent Arkerion Mono. Les ligatures transforment les suites de signes courantes en un seul symbole, sans changer le texte réel ni l'alignement :

```ts title="exemple.ts"
const isValid = (port: number) => port >= 1024 && port <= 65535;

if (process.env.NODE_ENV !== "production") {
  console.log(`Port valide : ${isValid(8080)}`);
}
```

:::info Version d'étude
Les polices Arkerion sont en cours de développement (version 0.1). Leur statut est détaillé sur la page [Polices](./identite/polices).
:::
