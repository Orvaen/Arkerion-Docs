## Logo

Le logo de Nebula suit l'identité d'Arkerion : même grille, mêmes arrondis, noir et blanc uniquement, et le nom composé en Arkerion Sans.

### Le symbole Amas

Un grand module, entouré de modules plus petits qui s'en détachent. Il évoque une nébuleuse, un nuage de matière qui se condense, tout en restant un assemblage de blocs, comme le symbole [Structure](../identite/logo) d'Arkerion. Le grand module reprend l'arrondi signature d'Arkerion, en haut à droite.

### Versions

Chaque version existe en noir, pour les fonds clairs, et en blanc, pour les fonds sombres.

<LogoGrid name="Nebula" prefix="nebula" dir="/img/nebula/" />

Les fichiers SVG se trouvent dans [`static/img/nebula`](https://github.com/Orvaen/Arkerion-Docs/tree/main/static/img/nebula). Le nom y est vectorisé : il s'affiche correctement même sans la police installée.

| Fichier | Usage |
|---|---|
| `nebula-logo-noir.svg`, `nebula-logo-blanc.svg` | Logo complet, usage principal |
| `nebula-symbole-noir.svg`, `nebula-symbole-blanc.svg` | Icône d'application, favicon |
| `nebula-nom-noir.svg`, `nebula-nom-blanc.svg` | Nom seul |
| `nebula-avatar-noir.svg`, `nebula-avatar-noir.png` | Avatar carré sur fond plein (1024 px) |
| `nebula-partage.png` | Carte de partage (1280 × 640), réseaux sociaux et GitHub |

### Aperçus

Le logo en situation, des grandes tailles jusqu'au favicon.

### Règles d'usage

Les règles du [logo Arkerion](../identite/logo) s'appliquent aussi à Nebula : même zone de protection, mêmes tailles minimales, pas de déformation, de recoloration ni d'effet. En plus :

:::danger Interdit
- Déplacer, retirer ou ajouter des modules : l'Amas compte toujours quatre blocs, dans cette disposition.
- Pivoter ou retourner le symbole : le grand module reste en haut à gauche.
- Associer le symbole Nebula au nom Arkerion, ou l'inverse.
:::
